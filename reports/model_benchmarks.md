# Model Benchmark Report

Current local dataset snapshot: 1,580 completed matches across 5 seasons.
This report is regenerated by `python3 run_full_pipeline.py`.

## Evaluation protocol

- Matches are sorted by kickoff. The first 80% form the development period; the final 20% are a chronological holdout.
- Candidate models are selected only within the development period using four expanding-window time-series folds.
- The selected candidate is evaluated once on the holdout. Regression preprocessing is fitted inside each fold; Ridge candidates standardize features.
- No recency sample weights are used. The 1X2 classifier excludes 2022-23 match rows from supervised fitting based on paired chronological holdouts; those matches remain in rolling feature history. Other model families refit on all eligible completed rows.
- The holdout scores describe the selected training procedure, not the all-data production artifact. The production artifact fits its calibrator from forward OOF predictions on all eligible training rows; its calibration is not the development-only holdout calibration.

## Read this before using the scores

- The primary results are from one chronological holdout. Season-by-season results above are repeated out-of-time checks; the latest partial season is provisional.
- Count-threshold predictions use an NB2 distribution with dispersion estimated on training data. Holdout scores compare NB2 and Poisson probabilities with the training-rate baseline; larger samples are still needed to judge calibration.
- 1X2 holdout predicted-class counts: `{0: 188, 1: 2, 2: 126}`; observed counts: `{0: 120, 1: 98, 2: 98}`. The classifier's argmax rarely selects draws, so its draw behavior needs separate calibration work.
- On the same main holdout, calibrated Dixon–Coles log loss was 1.0645 versus 1.0440 for the current classifier and 1.1146 for the class-prior baseline. It beats the prior but does not replace the current model.
- There is no trained xG model in this repository. The `home_xg` / `away_xg` fields are a hand-built proxy from aggregate shot counts and big chances, not Opta shot-level xG; the old MAE claim was unsupported and has been removed.
- Curated feature names live in each `src/models/train_*.py` file. Missing declared features now stop training instead of being silently dropped.

## Production artifacts

The API loads the current `.joblib` files from `models/production/`. Holdout metrics use a calibrator fit only on development-period forward OOF predictions. The production artifact uses a separate calibrator fit on forward OOF predictions from all eligible training rows: **1X2: 960/1,200**; **Over 2.5: 1,264/1,580**. These counts describe calibrator fit data, not independent performance results. Restart the API process to load a rebuilt artifact. Run the full pipeline after data changes to rebuild features, retrain models, and refresh this report.
